# Карта: визуализация, подложка MapTiler v4 и GeoServer — аудит этапа 11

План: этап 11 (визуализация карты), решения пользователя от 27.10.2026:

- **Сеть.** Цвета и смысл линий — как в десктопе (подача #7f0000, обратка #00007f,
  закрытые #808000, две линии). Улучшается только подача.
- **Здания.** Свести к одному виду. Подложку v4 детализировать.
- **GeoServer и nginx — прод всех городов.** Отладка на рабочей области `AlmatyGIS_test`, выкат —
  скриптами с бэкапом, их запускает пользователь.

Замеры — `scripts/perf/map-tiles.mjs` (снимки и запросы по зумам) и `scripts/perf/mvt-stat.mjs`
(состав тайла). Результаты «до»: `scripts/perf/results-2026-10-27-11a-*.json`, снимки —
`docs/map-audit/*-before-z*.jpg`.

- **Стенд Алматы:** 3040 (копия БД, GeoServer 8085 напрямую, HTTP/1.1, без gzip).
- **Стенд Астаны:** 3042 (GeoServer прода за защитой → 401, сеть не рисуется; снимки — подложка
  без сети).
