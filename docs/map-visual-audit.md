## После

### 11б — подложка v4 (`almaty-11b-z*.jpg`)

- **Палитра.** Одна — `PLANET_PALETTE` в `utils/planetV4Layers.ts`. Дороги белые со
  светло-серой обводкой, магистрали — приглушённый тёплый тон. Иерархия ширины: магистрали →
  главные → второстепенные → прочие.
- **Слоёв по умолчанию 25 вместо 8.** Добавлены:
  - зелень (газоны, лес, парки, кладбища);
  - землепользование (жилые зоны, промзоны, образование, больницы);
  - водотоки и их подписи, ж/д с z11;
  - тропинки и пешеходные зоны с z15;
  - районы — капители с z11;
  - номера домов с z17;
  - POI: образование, медицина, станции.
  Все POI серые с z16, станции — с z10.
- **Сохранённые наборы.** `PLANET_PREFS_VERSION` 3: новые умолчания доходят и до пользователей с
  сохранённым набором слоёв подложки.
- **Здания.**
  - «Здания» контекста в плане (наклон < 10°) — заливка `context-buildings-flat`: цвет назначения,
    осветлённый к фону на 45 %.
  - При наклоне — прежний объём `fill-extrusion`. В 2D проход объёмов не рисуется.
  - Плоские здания подложки (`base-planet-building`) по умолчанию выключены как дубль.
  - Легенда назначений и подсказка при наведении работают в обоих режимах.

### 11в — подача сети (`almaty-11v-z*.jpg`)

- Под каждой трубой — белая обводка (подслой `casing-*` того же фильтра, зумов и смещения, ширина
  трубы + 2 px). Пара подача/обратка читается на зданиях, ТУ и спутнике. Цвета линий — как в
  десктопе.
- **Порядок:** подсветка ПТС → обводки → распределительные → магистрали → подписи.
  - Делает `utils/networkStyleTuning.ts` в `server/api/geoserver-layers.ts`.
  - Обводки — обычные подслои пакета стиля, поэтому фильтр фрагментов, видимость и прозрачность
    работают с ними как с трубами.
- **Отказ от `icon-allow-overlap: false` у ИС/НС.** Подписи узлов стоят выше значков в порядке
  столкновений и прятали бы значки источников.

### 11г — здания (`AlmatyGIS_test`, `almaty-11g-z*.jpg`, `results-2026-10-27-11g-test-ws.json`)

- **`scripts/geoserver/web_map_styles.py`** (бэкап и откат) ставит стили по умолчанию:
  - **`zdaniya_2_web`** — здания с нагрузкой: светлая тёплая заливка #ecdcd5 и контур #b39c94
    с z14. Правило подписей — прежнее (`txt` в доме).
  - **`zdaniya_tu_web`** — ТУ: янтарная заливка 0.1 и контур/трасса 1 px с z14. Раньше было
    `generic` → WMS-растр.
- **Масштаб правил стиля GeoServer применяет и к векторным тайлам.**
  - Тайлы `zdaniya_2` на z11–13 пустые: было 2,4 МБ и 412 КБ.
  - `zdaniya_tu` идёт векторными тайлами из кеша GWC. Для этого `gwc_mvt_cache.py` включил слою
    сетку.
- **Фильтр фрагментов только у слоёв с полем `fileid`.**
  - Флаг `hasFragmentField` в `LayerConfig` берётся из атрибутов featuretype.
  - Раньше фильтр `fileid in (…)` прятал `zdaniya_2` целиком. «Здания (контуры)» не рисовались
    при любом выбранном фрагменте — на снимках «до» видны только подписи домов.
- **Подписи домов.** Дробные значения — до трёх значащих цифр (`Qсум=0.0764841` → `Qсум=0.0765`,
  `roundLabelNumbers`). Точные значения — в карточке.
- **Сводка у точки клика.** У объектов без вкладок десктопа (здания) — первые заполненные поля без
  служебных. Раньше выводилось «Атрибуты не заполнены».

### 11д — GeoServer, GWC и nginx

- **Поля тайла зданий** (`web_map_styles.py --slim-attributes`).
  - В `zdaniya_2` остаются поля карты и «Подписей»: `objectid`, `otop`, `gvs`, `vent`, `par`,
    `nagr`, `txt`, `floor`, `number_1`, `street_nam`, `year_of_fo`, `potrebitel`.
  - Убраны `shape_area`, `shape_leng`, `street2`, `house2`, `mkr2`, коды районов и схем.
  - Тайл z14 стал 34,5 КиБ в gzip против 44,5 (−22 %), z15 — 14,7 против 18,8.
  - Главный вес — `txt`, он нужен подписям. Карточка читает все поля по WFS из `id_zdaniya_2`.
- **Кеш в nginx и браузере** (`H:\deploy\gwc-nginx-cache-2026-10-27.cmd`, запускает пользователь).
  - Отдельный location для `/geoserver/<Область>/gwc/service/wmts`: та же проверка входа, кеш nginx
    на сутки только для GetTile, браузеру — `Cache-Control: private, max-age=86400`.
  - Кеш `geoserver_cache` увеличен: 200 МБ → 2 ГБ.
  - Холостой прогон на копии конфига: `nginx -t` успешен, боевой конфиг не тронут.
- **Квота GWC** (`gwc_mvt_cache.py --disk-quota-gb`). Сейчас квота выключена, кеш GWC — 1,2 ГБ на
  диске C: (занят на 92 %). У участков Алматы уже 390 наборов параметров — по версиям `rev` и
  наборам фрагментов. Предлагаемая квота — 5 ГБ, вытеснение LRU.
- **Срок кеша GWC.** `expireCache` 300 с → 0 (`gwc_mvt_cache.py --expire 0`). Тайл одной версии
  `rev` не устаревает, и перерисовка раз в 5 минут лишняя.
- **Версия данных.** Счётчики записей `almatygid` опрашивались напрямую из `pg_stat_user_tables` (тот
  же расчёт, что `DATA_VERSION_SQL`; API прода требует входа) — 35 снимков за 18 минут,
  27.10 18:38–18:56. Изменений не было: `rev` вечером стабилен, кеш по версии работает.
  Сужать `DATA_VERSION_SQL` до таблиц карты пока незачем — повторить замер в рабочее время.

### 11е — выкат на прод (скрипты готовы, запускает пользователь)

- **`H:\deploy\update-map-tiles-2026-10-27.cmd`** — один запуск для всех городов. Порядок:
  1. Проверки без изменений: коммит скриптов, Python, пароль, `--check` по городам.
  2. Кеш GWC переносится в `H:\geoserver-cache\gwc`: хранилище `tgid_cache` по умолчанию.
     Проверено на `AlmatyGIS_test` — служба GeoServer пишет на H:, повтор тайла даёт HIT.
  3. Квота кеша GWC — 20 ГБ, вытеснение LRU.
  4. `web_map_styles.py --slim-attributes`:
     - Алматы — оба стиля зданий;
     - остальные 10 городов — «Здания ТУ» (`zdaniya_2` там нет);
     - стиль не ставится, если у слоя нет полей `otop`/`txt`.
  5. `gwc_mvt_cache.py --expire 0` для участков, узлов и ТУ всех городов и `zdaniya_2` Алматы: 34
     слоя, холостой прогон пройден. Сброс раз в 5 минут отменяется для всех слоёв: адрес тайла
     версионирован `rev`, и при правке в базе меняется сам адрес.
  6. nginx — `gwc-nginx-cache-2026-10-27.ps1`, кеш в `H:\nginx-cache\geoserver`, `use_temp_path=off`.
- **Веб выкатывается после этого скрипта**, обычным обновлением.
- Старые каталоги `C:\ProgramData\GeoServer\gwc` (1,2 ГБ) и `C:\nginx\cache\geoserver` больше не
  пополняются. Удалить вручную после проверки.
- Скрипты, которые чистят кеш nginx (как `hide-deleted-fragments`), теперь должны чистить
  `H:\nginx-cache\geoserver`.
