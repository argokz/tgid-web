# Пьезометрический график: выбор маршрута и профиль

Дата: 2026-07-24.

## Что изменилось

Раньше пьезометр строился строго между **двумя** узлами (старт → финиш, кратчайший путь). В десктопе (`gid8/cxema/graph2.cpp`) направление задаётся выделением участков/последовательностью узлов, поэтому веб доведён до того же уровня выбора маршрута.

### Выбор маршрута через несколько узлов

- Режим трассировки: кликаешь по узлам сети **по порядку** — маршрут проходит через все выбранные точки (waypoints). Между соседними точками строится кратчайший путь, что позволяет направить трассу через нужные участки, а не только «напрямую».
- Панель «Маршрут пьезометра» на карте: список выбранных узлов (первый — зелёный, последний — красный), кнопки «Построить график», «Отменить точку», «Очистить».
- Маркеры точек и **подсветка построенного маршрута** оранжевой линией на карте; карта центрируется на маршруте.

### API

- `GET /piezometer/path?start=&end=` — прежний двухузловой маршрут (обратная совместимость).
- `POST /piezometer/route` — `{ "nodes": [id1, id2, id3, …] }` — маршрут через последовательность узлов. Возвращает по каждому узлу пути: расстояние, отметку `z`, напоры `h_pod/h_obr`, температуры `t_pod/t_obr`, координаты и метку узла; а также `total_length`, `node_count`, `has_calculation`.

Параллельные рёбра схлопываются в кратчайшее; несвязные узлы → 404 с указанием пары; меньше 2 узлов → 422.

### График и таблица

- Кривые: напор в подающем, напор в обратном, рельеф Z. Если в `pt_out` есть температуры — добавляются две пунктирные кривые t на второй оси.
- Вкладка **«Таблица узлов»**: № · узел · L · Z · H под. · H обр. · t под. · t обр.
- Экспорт профиля в **CSV** (с BOM для Excel).
- Клик по точке графика/строке таблицы центрирует карту на узле.
- Если расчётных напоров нет (`has_calculation=false`) — показывается профиль рельефа с пояснением, без фиктивных нулей.

## Ограничение данных

В текущей БД расчётные напоры неполные: нет ни одного участка, у которого **оба** конца имеют ненулевой `calcpressflow`, а таблица температур `pt_out` пуста. Поэтому сейчас на графике достоверно строится профиль рельефа и геометрия маршрута; напоры и температуры появятся после выполнения гидравлического расчёта сети и сохранения результата. Структура API и UI к этому готова.
