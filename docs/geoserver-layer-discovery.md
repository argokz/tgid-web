# Гибкое обнаружение и настройка слоёв GeoServer

Дата: 2026-07-23.

## Как это работает

Список слоёв больше не ограничен `GEOSERVER_LAYER_CATALOG` — сервер (`server/api/geoserver-layers.ts`) объединяет три источника:

1. **Каталог** (`GEOSERVER_LAYER_CATALOG` в `.env`) — подписи, режимы MVT/WMS, формат по умолчанию. Слои каталога **включены по умолчанию**.
2. **WMTS GetCapabilities** (GWC) — все тайловые слои; для них возможен MVT.
3. **WMS GetCapabilities** — слои, опубликованные без GWC-кэша (только WMS-отрисовка).

Все обнаруженные слои попадают в панель «Слои», сгруппированы по workspace, с чекбоксом видимости, прозрачностью, порядком и переключателем MVT/WMS. **Автообнаруженные слои по умолчанию выключены** — первая загрузка карты не тянет все 30+ опубликованных слоёв.

## Классы слоёв

| Класс | Примеры | Поведение |
|---|---|---|
| Рабочие (`role: data`) | `AlmatyGIS:heatpipesections`, `Almaty2:ctp` | Обычные слои панели |
| Query-слои (`id_*`) | `Almaty2:id_ctp`, `AlmatyGIS:id_heatpipesections` | **В панель не попадают.** Автоматически привязываются к базовому слою как `queryLayerName` и используются для WMS GetFeatureInfo (отдают `id`/`tab` объекта) |
| Вспомогательные (`role: service`) | `city_center`, `file`, `find_node`, `fragments` | Отдельная свёрнутая группа «… — вспомогательные», выключены по умолчанию |

Слои-группы workspace (`Almaty2:Almaty2`) отбрасываются как агрегаты.

## Русские названия

Приоритет подписи: `label` из каталога → `ows:Title` из GeoServer (там уже русские названия: «ЦТП», «Трубопроводы теплоснабжения»…) → техническое имя.

## Настройка (env)

```bash
# Какие workspace обнаруживать (кроме каталожных): список или '*' — все
GEOSERVER_DISCOVER_WORKSPACES=AlmatyGIS,Almaty2

# Имена вспомогательных слоёв (дефолт показан)
GEOSERVER_SERVICE_LAYERS=city_center,file,find_node,fragments
```

В каталоге у слоя появилось поле `queryLayer` — явное имя query-слоя, когда оно
не совпадает с шаблоном `id_<source>` (например, `uzel` → `id_nodes`):

```json
{"source": "uzel", "label": "Узлы теплосети", "mvt": true, "wms": true, "queryLayer": "id_nodes"}
```

## Производительность

- MBStyle/SLD-стили — самая дорогая часть (2–4 REST-запроса на слой): загружаются **параллельно** (лимит 6), результат кэшируется на 1 час (`?refresh=true` — принудительное обновление).
- Query- и вспомогательные слои стили не запрашивают.
- В панели добавлен **поиск по слоям**.
- `syncContextLayersToMap` больше не роняет инициализацию, если стиль карты ещё грузится (откладывается до `load`).

## Проверено на боевом GeoServer (itwin.kz)

47 опубликованных слоёв → 21 в панели: 8 каталожных (видимы), 12 автообнаруженных Almaty2 (скрыты, с русскими Title и готовыми MVT-стилями), 1 вспомогательный; 19 слоёв получили привязку `id_*` для запросов.
