# Панели интерфейса и отказоустойчивость

Дата: 2026-07-23.

## Разделение панелей

Инструменты разделены по назначению — карта больше не смешивает картографию с прикладными реестрами.

| Панель | Где | Содержимое |
|---|---|---|
| **Инструменты** | Выдвижная панель справа, открывается кнопкой в верхней навигации и с карты | 22 инструмента в 4 группах: эксплуатация, оборудование сети, расчёты и диагностика, реестры и отчёты. Поиск, подписи и пояснения к каждому пункту |
| **Рисование и измерения** | Плавающая панель над картой | Точка, линия, полигон; измерение расстояния и площади; отмена, очистка, выгрузка в GeoJSON |
| **Слои** | Левая панель (как было) | Слои карты, фрагменты, подписи |
| **Управление картой** | Правый столбец (10 кнопок) | Поиск адреса и узлов, identify, пьезометр, редактирование топологии, начальный вид, 2D/3D, геолокация, зум, подложка |

Панели инструментов и рисования взаимно исключают друг друга (`stores/uiStore.ts`), чтобы не перекрывать карту.

Каталог инструментов вынесен в [utils/toolCatalog.ts](../utils/toolCatalog.ts) — единый источник для панели и любых будущих точек входа.

## Рисование и измерения

Реализовано нативно на источниках/слоях MapLibre ([composables/useMapDraw.ts](../composables/useMapDraw.ts)) — без `mapbox-gl-draw`, который рассчитан на mapbox-gl и работает с MapLibre только через ломкую прослойку.

- Расстояния — формула гаверсинуса; площадь — сферическая формула Гаусса.
- Единицы подбираются автоматически: м / км, м² / га / км².
- Черновая геометрия рисуется пунктиром с «резиновой» линией до курсора.
- Слои рисования добавляются на карту только при открытой панели и снимаются при закрытии.
- 9 unit-тестов на геометрию и форматирование ([tests/composables/useMapDraw.spec.ts](../tests/composables/useMapDraw.spec.ts)).

## Отказоустойчивость и обработка ошибок

### Транспортный слой (`services/fastApiService.ts`)

Раньше `request()` — через который идут все журналы — вызывал `$fetch` напрямую: без таймаута и без ретраев, а существовавший `fetchWithRetry` не использовался и повторял даже 4xx.

Стало:

- **Таймаут 30 с** на каждый запрос;
- **Ретраи только там, где они уместны**: сетевые сбои, 408, 429, 5xx — экспоненциальная пауза с джиттером (400 мс → 800 мс);
- **Мутации не повторяются** (POST/PUT/DELETE) — исключены задвоенные записи;
- **Класс `ApiError`** с полями `status`, `detail`, `userMessage` и признаками `isRouteMissing` / `isUnavailable`;
- **Человеческие сообщения** по статусу: 401 — требуется авторизация, 404 на коллекции — «маршрут отсутствует, вероятно устаревшая версия API», 422 — некорректные параметры, 5xx — ошибка сервера.

### Индикатор состояния API

Реактивный `apiHealth` отслеживает доступность и наличие маршрутов. В layout появился баннер, который сразу показывает, что сервер недоступен или на нём развёрнута устаревшая версия — вместо молчаливых пустых диалогов.

### Сторона API

- `GET /health` (и `/api/health`) — статус БД с задержкой ответа, число маршрутов, готовность справочников. Для мониторинга и проверки деплоя.
- **Пул соединений настраивается**: `DB_POOL_MIN_SIZE` (2), `DB_POOL_MAX_SIZE` (20), `DB_COMMAND_TIMEOUT` (60 с), `DB_POOL_MAX_INACTIVE_LIFETIME` (300 с). Было жёстко `max_size=10` без таймаута команды — под нагрузкой очередь копилась, а зависший запрос удерживал соединение.
- Ошибки типа «таблица не того рода» (`/line/` для точечной таблицы) отдают **400 с пояснением**, а не 500.

## Смоук-проверка всех функций

Скрипт [scripts/smoke_all.py](../../itwin-api/itwin-api/scripts/smoke_all.py) обходит таблицу маршрутов приложения, подставляет реальные ID из журналов и печатает статус каждого эндпоинта.

```bash
python scripts/smoke_all.py --base http://127.0.0.1:8000
```

Результат последнего прогона: **68 OK, 0 ошибок**, 10 маршрутов возвращают пустые данные (в БД нет записей), 11 пропущено (карточки для пустых таблиц).

Найдено и исправлено этим прогоном:

1. `GET /api/calculations/latest` — 500: в SQL был потерян параметр (`LIMIT` без `$1`);
2. `GET /api/corrosion-indicators/geojson` — 500: обращение к несуществующей колонке `name` (в `indikator_korrozii` подпись собирается из номера индикатора и места установки);
3. `GET /line/{table}/{id}` — 500 при точечной таблице; теперь 400 с пояснением.
