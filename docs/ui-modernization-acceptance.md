Найдено и исправлено за этап 9 (в приложении, не в тестах):

- У активного поля (дата, выбранное значение) Vuetify прятал основную подпись `visibility: hidden` — у поля не было
  имени для читалки экрана (axe critical `label` в четырёх журналах). `assets/styles/_a11y.scss`.
- Подписи полей и вторичный текст — 4,22:1 при норме 4,5:1 → `medium-emphasis-opacity` 0,68 в теме.
- Каждый выпадающий список `AppSelect` читалка называла «Открыть»: `VSelect` пишет `open-text` в `aria-label` и
  `title` самого поля. Теперь имя — подпись поля.
- Кнопки раскрытия строк в «Истории правок» без имени (axe critical `button-name`, 50 на странице).
- 145 пустых `role="tooltip"` от закрытых подсказок (Lighthouse `aria-tooltip-name`) — у `HintTip` и подсказки
  координат теперь `aria-label`.
- Заголовок раскрывающейся группы в меню телефона — `role="button"` с `aria-expanded` вместо недопустимого
  `aria-selected`.
- `robots.txt` был пустым, `meta robots` не было: стенды теперь закрыты от индексации, у прода — `canonical`.

## Lighthouse

gzip (на проде сжимает nginx), CPU и сеть — умолчания Lighthouse для desktop и mobile.

\* 63 — стенд с `noindex` (так и задумано: `is-crawlable` не проходит), 100 — та же сборка с
`NUXT_PUBLIC_SITE_INDEXABLE=true NUXT_PUBLIC_SITE_URL=https://itwin.kz/itwin-map/`.

**Performance ≥ 90 не достигнут.** Метрику определяют не правки модернизации: TBT и LCP — это разбор и
инициализация MapLibre (785 KiB) и WebGL, тайлы сети и подложки (6+ MB на старте) и render-blocking
`vuetify.css` (384 KiB, из них не используется ~354). CLS снижен в 10 раз (0,043 → 0,004), TBT desktop — на 22–33 %.
Чтобы выйти на 90, нужны отдельные работы вне UI: критический CSS и отложенный остаток `vuetify.css`, отложенная
инициализация карты после первого кадра шапки, сжатие тайлов на GeoServer/nginx (`gzip`/`br` для MVT), предзагрузка
стиля. Для приложения за логином со «сплэшем» до первого кадра карты это приоритет ниже, чем S1–S9.

при загрузке страницы.

экрана: подсказки на всех кнопках карты и шапки, `AppLogo`), карта иконок MDI 73 → 79 KiB (новые иконки этапов 2–8),
`entry` 100 → 102 KiB. Бюджет 1 500 KiB не тронут, но условие «не больше этапа 1» не выполнено. План: разделить
`utils/mdiSvgPaths.ts` на иконки первого экрана и ленивую часть для диалогов (−20…30 KiB критического пути).

## Совместимость

Матрица (`browserslist` в `package.json`, ограничение 10 плана): последние 2 версии Chrome, Firefox, Safari, Edge,
Chrome Android; iOS Safari ≥ 16. Самое старое звено — Safari/iOS 16, поэтому столбец «минимум» сверяется с ним.
Сборка: `target: 'es2022'`, префиксы CSS добавляет autoprefixer Nuxt (в собранном CSS есть
`-webkit-backdrop-filter` и для `MapControls.vue`, где в исходнике префикса нет).

`structuredClone`, `Array.prototype.toSorted`/`findLast`, `Object.groupBy`, `Promise.withResolvers`, методы `Set`,
`Iterator`-хелперы в клиентском коде не используются (проверено поиском).

Где проверено: Chromium-движок — Chrome и Edge (Windows), все e2e. Firefox и WebKit в Playwright на этой машине не
установлены (браузеры Playwright не скачивались, см. `docs/e2e-smoke.md`); по таблице выше ни одна возможность не
выходит за матрицу, а там, где поддержка моложе Safari 16 (`linear()`), стоит `@supports`.
Данные `caniuse-lite` в зависимостях старые (сборка предупреждает) — обновление `update-browserslist-db` меняет
lock-файл, отложено до плановой правки зависимостей.

## Что не сделано и почему

| Пункт плана | Состояние | Причина и план |
|---|---|---|
| Lighthouse Performance ≥ 90 | 38 / 26 | MapLibre + WebGL + тайлы на старте + `vuetify.css`; план — в разделе «Lighthouse» |
| Критический JS не больше этапа 1 | +13,7 KiB | подсказки и знак с первого экрана, новые иконки; план — разделить `mdiSvgPaths` |
| S3b первое открытие журнала | +31 % | общие примитивы журналов грузятся при первом открытии; план — профиль и предзагрузка в простое |
| Playwright Firefox, WebKit, эмуляция iPhone / iPad / Pixel | не прогонялись | браузеры Playwright на машине не установлены; скачивание (~300 MB с CDN Microsoft) — по согласию. Конфиг проектов добавляется вместе с ними |
| Edge с масштабом 125 %, Safari на MacBook, трекпад | не проверено вручную | на этапе 7г проверены эквивалентные окна (1920 при 150 % = 1280 CSS px) в эмуляции, не в живом Edge; Safari — по предложению заказчика открыть стенд на MacBook |
